## 2. Catálogo — `public/js/core/` (9 módulos nuevos)

### `core/config.js` — config operativa del frontend
Espejo de `GET /api/config`. Regla del proyecto: **ningún número operativo se
escribe en una vista**; todas llaman `cfg("CLAVE")`. Arranque en 3 capas
(defaults → localStorage → fetch en background), nunca bloquea el boot.

| Función | Qué hace |
|---|---|
| `cfg(key)` | Lectura síncrona de una clave; siempre devuelve valor (fallback a DEFAULTS) |
| `cfgAll()` | Copia de la config completa (para Admin) |
| `loadConfig()` | Refresca desde el servidor, persiste en localStorage y emite `glp:configloaded`. No lanza |

### `core/poll.js` — polling adaptativo (reemplaza `setInterval` dispersos)
El intervalo se relee de `cfg(key)` en cada ciclo (el Admin lo cambia en vivo),
se pausa con `document.hidden` y ejecuta de inmediato al volver a primer plano.

| Función | Qué hace |
|---|---|
| `startPoll(key, fn, {immediate, cfgKey})` | Registra un poll gobernado por una clave de config; idempotente; devuelve `stop()` |
| `stopPoll(key)` | Detiene y desregistra |
| `pollNow(key)` | Fuerza un tick inmediato (lo usa SSE) |
| `pollNowByCfg(cfgKey)` | Fuerza el tick de todas las instancias con esa clave de config |

### `core/live.js` — cliente SSE ("sistema nervioso" del frontend)
Conecta a `GET /api/events`; cada topic del servidor dispara `pollNowByCfg` de
los polls asociados (tabla `TOPIC_TO_POLLS`) y re-emite `CustomEvent "glp:live"`.

| Función | Qué hace |
|---|---|
| `initLive()` | Abre la conexión EventSource (idempotente); topic `config` recarga la config |
| `stopLive()` | Cierra el stream (logout) |

### `core/domain-meta.js` — vocabulario visual único del dominio
Roles y estados con label/icono/color **siempre en tokens CSS** (`var(--…)`),
nunca hex sueltos. Ninguna vista debe definir sus propios colores de rol/estado.

| Función / const | Qué hace |
|---|---|
| `ROL_META` / `rolMeta(rol)` | Meta de MOTOR/TANQUE/CALIDAD/RAMALERO con fallback seguro |
| `ESTADO_META` / `estadoMeta(estado)` | Meta de TRABAJANDO/PAUSADO/… (badge, color, bg, live) |
| `progressTone(fraction)` | Semáforo 0..1 → token de color (criterio único para gauges/barras) |

### `core/drilldown.js` — bottom-sheet universal de detalle
Un solo nodo en el DOM reutilizado por todas las vistas; cierra con backdrop,
Escape y ✕. Es la base del "todo número agregado es clickeable".

| Función | Qué hace |
|---|---|
| `openDrilldown({title, subtitle, badge, html})` | Abre el panel; devuelve el body por si la vista bindea clicks internos |
| `closeDrilldown()` | Cierra y restaura el scroll de fondo |
| `isDrilldownOpen()` | Para no re-renderizar debajo del panel abierto |

### `core/viz.js` — helpers de data-viz (tokens + gauges SVG + Chart.js)
| Función | Qué hace |
|---|---|
| `clamp01(n)` | Acota a [0,1] con saneo de NaN |
| `readVizColors()` | Lee los tokens `--dv-*` del tema activo (re-llamar tras cambio de tema) |
| `gaugeHTML({fraction, display, sub, label, foot, tone})` | Gauge circular SVG cuyo stroke usa `var()` → sigue el tema sin re-render |
| `chartBaseOptions(c)` | Opciones base de Chart.js coherentes con los tokens |
| `verticalFill(ctx, area, hex, topAlpha, botAlpha)` | Gradiente vertical para relleno de áreas |
| `hexA(hex, a)` | `#rrggbb` → `rgba(...)` |
| `onThemeChange(cb)` | Suscribe al evento `glp:themechange`; devuelve unsubscribe |

### `core/ui-dynamics.js` — presentación viva compartida
| Función | Qué hace |
|---|---|
| `relTimeText(when)` | "hace 2 min" (es-PE, auto-unidad) |
| `startRelTimeTicker(intervalMs)` | Un solo ticker global refresca todos los `[data-reltime]` del DOM |
| `countUp(el, to, opts)` | Anima un número hasta su valor (respeta `prefers-reduced-motion`) |
| `skeletonHTML(rows, {height})` | Placeholder shimmer para estados de carga |

### `core/icons.js` — sistema de iconos SVG
Reemplaza emojis: stroke 24×24, `currentColor`, coloreables vía CSS.

| Función | Qué hace |
|---|---|
| `icon(name, size)` | Devuelve el `<svg>` inline del icono pedido (~40 nombres en `ICONS`) |
| `toroSvg(idSuffix)` | Avatar SVG "toro ejecutivo" para usuarios especiales |

### `core/settings-sheet.js` — panel global de apariencia
Tema + tamaño de texto + acento, accesible desde el topbar de cualquier módulo.

| Función | Qué hace |
|---|---|
| `openSettingsSheet()` / `closeSettingsSheet()` | Abre/cierra el sheet (se construye lazy una sola vez con `buildSheet_`) |

## 3. Catálogo — `lib/` backend (4 módulos nuevos)

### `lib/config.js` — fuente única de configuración operativa
`CONFIG_DEFAULTS` (metas, horarios, targets, intervalos de poll, límites) +
merge con la tabla `app_config` (editable desde Admin sin redeploy, cache 60s).
El frontend lo recibe vía `GET /api/config`. **Regla: ningún número operativo
hardcodeado en rutas ni vistas.**

### `lib/events.js` — bus SSE del servidor
| Función | Qué hace |
|---|---|
| `sseHandler_(req, res)` | Handler de `GET /api/events`; heartbeat cada 25s, headers anti-buffering |
| `emitEvent_(topic, data)` | Notifica a todos los clientes tras una mutación; nunca lanza |
| `sseClientCount_()` | Diagnóstico |

Topics: `asignaciones | ramal | incidencias | zonas | movilizador | config`.

### `lib/image-optimize.js` — normalización de imágenes server-side
Red de seguridad para R2: todo lo que entra se re-encoda a JPEG mozjpeg
≤800px q60; convierte HEIC de iPhone (heic-convert). `normalizeImage(buffer,
mimeType)` nunca lanza — si falla devuelve el original.

### `lib/push.js` — Web Push centralizado
`sendPushToEmails_(emails, {title, body, tag, data})` busca las suscripciones
en `push_subscriptions`, envía en paralelo, borra las caducadas (410) y nunca
lanza (best-effort).
